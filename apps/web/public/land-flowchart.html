1. Land Lifecycle — End-to-End Flow

From seller master → acquisition → partition → development → monetization (sale / rent / hold) → soft delete. Every transition is atomic, audited, and GL-posted.

4. LandParcel Status — State Machine

Every status transition is triggered by a specific service function and is audited. SOLD is terminal (cannot revert). PARTITIONED is reversible only via unpartition.

stateDiagram-v2
  direction TB

  [*] --> AVAILABLE : recordLandPurchase()\nrecordLandPurchaseWithPlan()

  AVAILABLE --> HOLD : setParcelStatus(HOLD)
  HOLD --> AVAILABLE : setParcelStatus(AVAILABLE)

  AVAILABLE --> PARTITIONED : partitionLandParcel()\nparent becomes inactive
  PARTITIONED --> AVAILABLE : unpartitionLandParcel()\n(if no SOLD children,\nno built units, no sales)

  AVAILABLE --> RESERVED : sellAsset(LAND)\n+ recordDeposit()\nDEPOSIT_RECEIVED
  HOLD --> RESERVED : sellAsset(LAND)\n+ recordDeposit()

  RESERVED --> SOLD : completeSale()\nfinal payment + title transfer
  RESERVED --> AVAILABLE : cancelSale()\nsale cancelled

  AVAILABLE --> RENTED : createTenancy(LAND)\n+ activateTenancy()
  HOLD --> RENTED : createTenancy(LAND)\n+ activateTenancy()
  RENTED --> AVAILABLE : terminateTenancy()

  SOLD --> [*] : terminal\n(soft-delete allowed)
  PARTITIONED --> [*] : soft-delete allowed\n(if no active children)

  note right of SOLD
    SOLD is terminal.
    Parcel cannot revert.
    Soft-delete permitted.
  end note

  note right of PARTITIONED
    Parent parcel is a container.
    Not sellable as a whole.
    Children are the sellable units.
  end note

A Acquisition

  • 2 entry points: recordLandPurchase() (simple) + recordLandPurchaseWithPlan() (guided wizard)
  • WHOLE mode → 1 sellable parcel; SUBDIVIDED → N sections at purchase time
  • Freehold vs Leasehold with lease period, rent type (one-time/yearly)
  • Full cost breakup: base + lease rent + GST + registration + stamp duty + brokerage + legal + other
  • Auto-creates OWNERSHIP_CERTIFICATE legal doc if registry number provided
  • Inline project creation inside the same atomic transaction

P Partition

  • Area conservation: Σ children area = parent area (exact, 3 decimals)
  • 2 allocation models: PRO_RATA (by area) + MARKET_VALUE (by area × weight)
  • Infrastructure plots (roads, parks) absorb zero cost — siblings absorb it
  • Development cost added to parent basis before allocation
  • Nesting allowed — a child can itself be partitioned later
  • Unpartition reverses if no SOLD children, no built units, no active sales
  • CAD canvas with polygon geometry stored as JSON

D Development

  • Parcels link to Projects via projectId
  • BuiltUnits (apartments, shops, villas) linked via landParcelId
  • Cost-per-sqft allocation: land cost → project pool → unit production cost
  • PURCHASED units excluded from area allocation (cost set at acquisition)
  • Renovation capitalizes cost into parcel's acquisition cost
  • Re-allocation runs after every material issue, project cost, or land purchase change

S Sale & Rental

  • Staged sale: PENDING → DEPOSIT_RECEIVED → COMPLETED (or CANCELLED)
  • Parcel status tracks sale: AVAILABLE → RESERVED → SOLD
  • Sale compliance: ATS, BBA, allotment letter, sale deed, TDS (Form 16B), home loan
  • Tenancy: create → activate (RENTED) → terminate (AVAILABLE)
  • Rent payments with GST via SAC codes (997212 non-residential, 997211 residential)
  • GL posts revenue + COGS + GST on sale completion

L Legal & Compliance

  • LegalDocument linked to LandPurchase + Project
  • Types: ownership cert, permissions, NOCs, ATS, sale deed, transfer duty
  • Guided checklist with sortOrder + prerequisiteType
  • Yes/No branching: obtained flag controls sub-form visibility
  • Validity tracking: issue date, valid from, valid till (expiry alerts)
  • Document upload (PDF/image) with reference numbers

G GL, Audit & Reporting

  • GL posting: Dr LAND_ASSET (1700) / Cr CASH on purchase
  • NRV write-downs: Dr OPERATING_EXP / Cr LAND_ASSET (if valuation < cost)
  • AuditLog on every mutation: CREATE, PARTITION, UNPARTITION, VALUATION, STATUS, SALE
  • Soft delete: LandPurchase (if no unsold parcels), LandParcel (if not AVAILABLE/HOLD)
  • Reporting: unsoldAssetValue(), projectTotalCost(), portfolio summary, RE inventory
  • Orbit visualization: land parcel + purchase nodes in relationship graph

C CRM & Leads

  • Lead pipeline: NEW → CONTACTED → SITE_VISIT → NEGOTIATION → BOOKED / LOST

  • LeadActivity log: CALL, EMAIL, WHATSAPP, MEETING, SITE_VISIT, NOTE, STAGE_CHANGE
  • Lead scoring with priority (LOW/MED/HIGH/HOT), budget range, next follow-up
  • Conversion tracking: convertedCustomerId + convertedAt
  • Lost leads tracked with lostReason

P Portal Listings

  • Syndicate BuiltUnits to 99acres, MagicBricks, Housing.com
  • Pluggable PortalProvider — stub logs, real provider calls portal API
  • Auto-populated from unit: bedrooms, bathrooms, area, floor, furnishing
  • Status: DRAFT → LISTED → DELISTED with lastSyncedAt + syncError
  • One listing per unit per portal (@@unique([builtUnitId, portalName]))
  • Photo array support for multi-image listings

S Payment Schedules

  • 3 plan types: CLP (construction-linked), TLP (time-linked), DPP (down payment)
  • CLP: installments tied to WBS milestone completion via wbsNodeId
  • TLP: fixed installments over time with dueDate
  • DPP: large upfront + small balance installments
  • Item status: PENDING → DUE → PARTIAL → PAID → WAIVED
  • GST tracked separately: gstAmount + grandTotal

T Transfer Duty Bridge

  • TRANSFER_DUTY legal doc → auto-creates ProjectCost line
  • Conditions: obtained=true, APPROVED, amount>0, projectId set
  • Cost type TRANSFER_DUTY with sourceLegalDocId back-link
  • Flows into cost-per-sqft allocation via reallocateProjectCosts()
  • GL posts via postProjectCost() — Dr WIP, Cr CASH
  • Idempotent: re-runs on every create/update, upserts by sourceLegalDocId
  • Removal reverses the GL entry and re-allocates

G GL Account Map

  • 1700 LAND_ASSET: Dr on purchase, Cr on sale (COGS), Cr on NRV write-down
  • 1100 CASH: Cr on purchase, Dr on deposit, Cr on sale, Dr on transfer duty
  • 2500 CUSTOMER_DEPOSIT: Cr on deposit, Dr on sale completion / cancel refund
  • 4000 SALES_REVENUE: Cr on sale completion
  • 2100 OUTPUT_GST: Cr on sale (if GST applicable)
  • 5000 COGS: Dr on sale, Cr LAND_ASSET
  • 6000 OPERATING_EXPENSE: Dr on NRV write-down
  • 1500 WIP: Dr on transfer duty, Cr on unit capitalization
